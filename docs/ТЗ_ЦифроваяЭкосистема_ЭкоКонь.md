## ЧАСТЬ 1: ОБЩЕЕ ОПИСАНИЕ ПРОЕКТА

### 1.1 Название и тип

- **Название:** Цифровая экосистема «Эко Конь / Цветология»
- **Домен:** ecokon.ru
- **Бизнес:** КФХ "Ранчо Мушкино", Гладышев Ю.Е.
- **Зонтичный бренд:** два суббренда под одной крышей:
  - **ЭКО Конь** — органические удобрения (био-чай, специализированные, грунты)
  - **Цветология** — системы вертикального озеленения (фитомодули, аксессуары)
- **Тип:** D2C экосистема: сайт + мобильное приложение + VK Shop + централизованная админка
- **Целевая аудитория:**
  - Женщины 35–65: комнатные растения, цветоводство
  - Городские садоводы: балконное озеленение, вертикальные сады
  - Дачники: огород, рассада, овощи
  - Дизайнеры интерьеров: фитомодули для офисов и кафе

### 1.2 Текущее состояние

- **Каналы продаж:** Ozon + Wildberries (50/50)
- **GMV Ozon (Чай, 2025):** 68.6M ₽/год (реальные данные)
- **Комиссия маркетплейсов:** 34.9% (inSales, март 2026)
- **Прибыль МП после всех расходов:** 28.5% (177 ₽/единица)
- **Отзывы:** 45 000+ (средний рейтинг 4.9–5.0 ⭐)
- **SKU на маркетплейсах:** 18+ позиций
- **Ozon ЭКО Конь:** 8 товаров, 27 292 отзыва
- **Ozon Цветология:** 5 товаров, 14 192 отзыва, 64 113 заказов
- **Wildberries ЭКО Конь:** 5 подтверждённых товаров
- **Сезонность:** пик июн-июл (~8M ₽/мес), спад окт-дек (~3M ₽/мес), коэффициент 2.5x

### 1.3 Цели D2C экосистемы

1. Увеличить маржинальность: D2C 40.1% vs МП 28.5% (+33% на единицу, +59 ₽/шт)
2. Собрать собственную базу клиентов (email, телефон, push-токены)
3. Запустить подписочную модель (рекуррентные поставки удобрений)
4. Кросс-продажи между линейками (удобрение + фитомодуль)
5. Выстроить воронку: Охват → Захват → Ретаргетинг → Удержание

### 1.4 Фазы реализации

**Phase 1 — MVP сайт (8 недель):**
- Полный каталог (18+ SKU, 5 продуктовых линеек)

**Phase 3 — Мультиканальность (6 недель):**

  marketplace_ids?: {            // Для синхронизации

### 3.3 Корзина и оформление заказа

**Страница корзины (/cart):**
- Список товаров: фото, название, бренд-лейбл, вариант, цена, кол-во (±), удалить, сумма строки
- Блок "Добавьте ещё на X ₽ для бесплатной доставки" (если порог > текущей суммы)
- Блок "Рекомендуем добавить" (2-3 товара для кросс-продаж)
- Промокод: поле + кнопка "Применить"
- Итого: товары, скидка, доставка (TBD), **итого**
- Кнопка "Оформить заказ" → /checkout
- Persist в localStorage (Zustand persist middleware)

**Страница оформления (/checkout) — 3 шага:**

**Шаг 1: Доставка (мультидоставка через ApiShip)**
- Город: autocomplete из справочника ApiShip
- Служба доставки + тип (radio, сгруппировано):
  - **5Post** (ПВЗ/почтоматы) — от 99 ₽, 3-7 дней
  - **Boxberry** (ПВЗ) — от 200 ₽, 3-7 дней
  - **Почта России** (отделения) — от 150 ₽, 5-14 дней
  - **СДЭК** (ПВЗ/почтоматы/курьер) — от 250 ₽, 2-5 дней
- Для каждой СД показывается: стоимость + сроки (расчёт через ApiShip)
- Автоматическая сортировка: сначала дешёвые
- Если ПВЗ/почтомат/отделение: карта Yandex Maps с маркерами + список (адрес, часы, телефон)
- Если курьер (СДЭК): адрес доставки (улица, дом, квартира, подъезд, этаж)
- Кнопка "Далее"

**Шаг 2: Данные получателя**
- Имя (обязательное)
- Email (обязательное, валидация)
- Телефон (обязательное, маска +7 (XXX) XXX-XX-XX)
- Комментарий к заказу (необязательное)
- Checkbox: "Сохранить адрес" (если залогинен)
- Кнопка "Далее"

**Шаг 3: Оплата и подтверждение**
- Способ оплаты (radio):
  - ☐ Банковская карта (YooKassa)
  - ☐ СБП (Система быстрых платежей)
  - ☐ SberPay
  - ☐ Tinkoff Pay
  - ☐ Рассрочка (YooKassa installments)
  - ☐ Наложенный платёж (СДЭК/Почта России, +комиссия)
- Order Summary:
  - Товары (список): ХХХ ₽
  - Доставка: ХХХ ₽
  - Скидка: -ХХ ₽
  - **Итого: ХХХ ₽**
- Checkbox: "Согласен с офертой" (link /terms)
- Кнопка "Оплатить ХХХ ₽" → YooKassa redirect

**Guest checkout:** анонимный заказ (без регистрации)
**Registered flow:** данные подтянуты из профиля, ускоренный checkout

**Страница подтверждения (/order/[id]):**
- "Спасибо за заказ!"
- Номер заказа, дата, сумма, статус
- Данные доставки (ПВЗ адрес или курьерский адрес)
- Трек-номер (когда появится) + название службы доставки
- Кнопка "Отследить заказ" → ссылка на трекинг выбранной СД

- Email-подтверждение отправляется асинхронно

```sql
-- profiles: только свой профиль
ALTER TABLE profiles ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Users can view own profile" ON profiles FOR SELECT USING (auth.uid() = user_id);
CREATE POLICY "Users can update own profile" ON profiles FOR UPDATE USING (auth.uid() = user_id);

-- orders: только свои заказы (или admin)
ALTER TABLE orders ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Users can view own orders" ON orders FOR SELECT
  USING (auth.uid() = user_id OR EXISTS (SELECT 1 FROM profiles WHERE user_id = auth.uid() AND role = 'admin'));

-- favorites: только свои
ALTER TABLE favorites ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Users can manage own favorites" ON favorites FOR ALL USING (auth.uid() = user_id);

-- reviews: public read, authenticated insert
-- admin таблицы: только role = 'admin'

## 8. ИНТЕГРАЦИИ

### 8.1 Мультидоставка через ApiShip (агрегатор)

**Почему ApiShip:**
- Единый API для 4+ служб доставки → не надо интегрировать каждую отдельно
- Автоматический выбор оптимального тарифа
- Единый трекинг и вебхуки
- Средняя стоимость доставки ~150 ₽ (vs СДЭК-only ~350 ₽)

**Службы доставки:**

| СД | Тип | Стоимость | Сроки | Покрытие |
|---|---|---|---|---|
| 5Post | ПВЗ, почтоматы | 99–150 ₽ | 3-7 дней | 5 000+ точек |
| Boxberry | ПВЗ | 200–280 ₽ | 3-7 дней | 4 500+ точек |
| Почта России | Отделения | 150–220 ₽ | 5-14 дней | 42 000+ отделений |
| СДЭК | ПВЗ, почтоматы, курьер | 250–550 ₽ | 2-5 дней | 3 000+ точек |

**Авторизация:**
- ApiShip API Key → header `Authorization: Bearer <token>`
- Один ключ для всех СД

**Endpoints:**

```
POST /api/delivery/calculate      → Расчёт тарифов всех СД одновременно
POST /api/delivery/pvz            → Список ПВЗ/почтоматов/отделений по городу (все СД)
POST /api/delivery/cities         → Справочник городов (autocomplete)
POST /api/delivery/create-order   → Создать заказ в выбранной СД
GET  /api/delivery/track/[id]     → Отследить заказ (единый трекинг)
POST /api/delivery/webhook        → Webhook статусов от ApiShip
```

**Расчёт тарифов (все СД одновременно):**

### 12.1 Архитектура

```
┌─────────────┐
│  Admin Panel │  ← Единственный источник правды
│  (Supabase)  │
└──────┬───────┘
       │ Supabase Realtime / Edge Functions
       │
  ┌────┴────┬──────────┬──────────┐
  │         │          │          │
  ▼         ▼          ▼          ▼
 Site      VK Shop    App       Ozon/WB
(Next.js) (VK API)  (PWA/RN)  (future)
```

### 12.2 Event-driven sync

- Триггер: `products` table UPDATE → Supabase Realtime → Edge Function
- Edge Function: определяет какие каналы затронуты → отправляет обновления
- Для VK: `market.edit` API call
- Для App (PWA): автоматически через shared API
- Для App (RN): push notification + API refresh
- Логирование в `sync_log`

### 12.3 Конфликты

- Admin всегда побеждает (single source of truth)
- Заказы из VK/App → только создание (не редактирование товаров)
- Остатки: admin задаёт, каналы только читают

```

**ApiShip клиент (lib/apiship.ts):**
- `calculateAll(from, to, weight, dimensions)` → тарифы всех 4 СД, отсортированные по цене
- `getPickupPoints(cityId, providers?)` → ПВЗ/почтоматы/отделения по городу (все СД)
- `getCities(query)` → autocomplete городов (единый справочник)
- `createOrder(provider, orderData)` → ID заказа в ApiShip
- `trackOrder(orderId)` → единый статус доставки
- `handleWebhook(body)` → обработка событий от всех СД

**DeliveryMap компонент:**
- Yandex Maps JS API v3
- Маркеры ПВЗ/почтоматов/отделений всех 4 СД (разные цвета)
- Фильтр по СД: checkbox для каждой
- Кластеризация маркеров
- Popup: СД, адрес, режим работы, стоимость, кнопка "Выбрать"
- Responsive: карта + список под ней на мобиле

**DeliveryOptions компонент:**
- Список вариантов доставки (radio buttons), сгруппированных по типу
- Для каждого: лого СД, название, стоимость, сроки
- Автоматическая сортировка по цене (дешёвые сверху)
- Подсветка рекомендуемого варианта (оптимальное соотношение цена/скорость)
