# Blog → Яндекс.Дзен (Phase 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Publish the blog to Яндекс.Дзен as a syndication channel that drives traffic back to the site — via a Dzen-compatible RSS feed plus an operational playbook.

**Architecture:** A `force-dynamic` Route Handler at `/blog/feed.xml` emits RSS 2.0 with full `content:encoded` (markdown→HTML, links absolutized, clean ЧПУ item URLs without UTM). The actual Dzen connection is operational (manual, gated on the channel reaching 10 subscribers + domain verification) and documented in a playbook. Until the channel qualifies for RSS auto-import, posting is manual copy-paste of full text.

**Tech Stack:** Next.js 14 App Router Route Handler, Prisma, `marked` (new dep, markdown→HTML string), existing `blogCategoryLabel` from `@/lib/blog`.

**Spec:** `docs/superpowers/specs/2026-06-02-blog-engagement-design.md` (Фаза 2).

**Key Dzen constraints (from dzen.ru/help, verified 2026-06):**
- Channel needs **10 subscribers** + verified site (HTML file / meta tag) before RSS broadcast can be connected.
- Feed needs **≥10 items**; site needs **≥3 posts in the last month**.
- Item URLs must be **ЧПУ without UTM/params**.
- Feed validation is limited to **3 attempts per year** — get it right first.

Create `src/app/blog/feed.xml/route.ts`:
```ts
import { prisma } from "@/lib/prisma";
import { marked } from "marked";
import { blogCategoryLabel } from "@/lib/blog";

export const dynamic = "force-dynamic";

const SITE = "https://pro-pochvu.ru";

function xmlEscape(s: string): string {
  return s
    .replace(/&/g, "&amp;")
    .replace(/</g, "&lt;")
    .replace(/>/g, "&gt;")
    .replace(/"/g, "&quot;");
}

function cdata(s: string): string {
  // Безопасно вкладываем HTML в CDATA, экранируя возможный ]]>
  return `<![CDATA[${s.replace(/\]\]>/g, "]]]]><![CDATA[>")}]]>`;
}

// Относительные ссылки/картинки в контенте делаем абсолютными для Дзена/ридеров.
function absolutize(html: string): string {
  return html.replace(/(href|src)="\/(?!\/)/g, `$1="${SITE}/`);
}

type FeedPost = {
  slug: string;
  title: string;
  excerpt: string | null;
  content: string;
  coverImage: string | null;
  category: string | null;
  publishedAt: Date | null;
  updatedAt: Date;
};

export async function GET() {
  let posts: FeedPost[] = [];
  try {
    posts = await prisma.blogPost.findMany({
      where: { isPublished: true },
      orderBy: { publishedAt: "desc" },
      take: 50,
      select: {
        slug: true,
        title: true,
        excerpt: true,
        content: true,
        coverImage: true,
        category: true,
        publishedAt: true,
        updatedAt: true,
      },
    });
  } catch (e) {
    console.error("rss feed db error", e);
    // На ошибке БД — отдаём валидный пустой фид, не 500.
  }

  const items = posts
    .map((p) => {
      const url = `${SITE}/blog/${p.slug}`; // ЧПУ без UTM — требование Дзена
      const date = (p.publishedAt ?? p.updatedAt).toUTCString();
      const cover = p.coverImage
        ? `<figure><img src="${SITE}${p.coverImage}" alt="${xmlEscape(p.title)}"></figure>`
        : "";
      const bodyHtml = absolutize(marked.parse(p.content, { async: false }) as string);
      const cat = blogCategoryLabel(p.category);
      return [
        "<item>",
        `<title>${xmlEscape(p.title)}</title>`,
        `<link>${url}</link>`,
        `<guid isPermaLink="true">${url}</guid>`,
        `<pubDate>${date}</pubDate>`,
        `<author>noreply@pro-pochvu.ru (Пропочву)</author>`,
        cat ? `<category>${xmlEscape(cat)}</category>` : "",
        p.excerpt ? `<description>${xmlEscape(p.excerpt)}</description>` : "",
        p.coverImage
          ? `<enclosure url="${SITE}${p.coverImage}" type="image/jpeg" />`
          : "",
        `<content:encoded>${cdata(cover + bodyHtml)}</content:encoded>`,
        "</item>",
      ]
        .filter(Boolean)
        .join("");
    })
    .join("\n");

  const xml = `<?xml version="1.0" encoding="UTF-8"?>
<rss version="2.0" xmlns:content="http://purl.org/rss/1.0/modules/content/" xmlns:media="http://search.yahoo.com/mrss/">
<channel>
<title>Блог Пропочву — о растениях, удобрениях и озеленении</title>
<link>${SITE}/blog</link>
<description>Уход за растениями, органические удобрения, грунты и вертикальное озеленение от КФХ «Ранчо Мушкино».</description>
<language>ru</language>
<lastBuildDate>${new Date().toUTCString()}</lastBuildDate>
${items}
</channel>
</rss>`;

  return new Response(xml, {
    headers: {
      "content-type": "application/rss+xml; charset=utf-8",
      "cache-control": "public, max-age=900",
    },
  });
}
```

Note on `marked`: in current `marked`, `parse()` is synchronous and returns a string by default; `{ async: false }` makes the string return type explicit. If TypeScript complains about the return type, cast with `as string` (already done).

## Task 2: Dzen operational playbook

**Files:**
- Create: `docs/DZEN_PLAYBOOK.md`

This is a documentation task — no code. Write a concise, accurate playbook (the controller writes it directly during execution, since it encodes web-researched Dzen requirements). It must contain:

1. **Предусловия для RSS-трансляции:** канал в Дзене + 10 подписчиков + подтверждение прав на домен (HTML-файл или мета-тег) + ≥3 публикации на сайте за последний месяц + ≥10 материалов в ленте.
2. **Где взять ленту:** `https://pro-pochvu.ru/blog/feed.xml`.
3. **Подключение:** Дзен → Настройки → «Свой сайт» → добавить домен → подтвердить права → «Настроить трансляцию материалов сайта в Дзен» → отправить ленту на проверку. **Внимание:** проверок не более 3 в год — сверить ленту с актуальными требованиями `dzen.ru/help/ru/export-content/export.html` перед отправкой.
4. **До набора 10 подписчиков:** публиковать вручную (copy-paste полного текста статьи из админки/markdown), 2–4 раза в неделю, начиная с бэклога 32 статей.
5. **Ссылки:** в теле статьи 2–3 контекстные ссылки на товары/разделы (уже есть). URL `<item>` — ЧПУ без UTM (требование Дзена соблюдено в фиде). Атрибуция переходов — по referrer.
6. **Гигиена дублей:** публиковать в Дзен с задержкой относительно сайта, чтобы наша страница (оригинал) проиндексировалась первой.
7. **Замер:** в Яндекс.Метрике — источник `dzen.ru` (referral); настроить цель «клик на товар» для трафика с этим источником; смотреть переходы на сайт и далее на маркетплейс.
8. **Частота и приоритет тем:** начинать с самых сильных статей (грунт/удобрения/уход), затем новые по мере выхода.
